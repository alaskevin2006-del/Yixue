# 逸学｜Visual Design

## 1. 视觉目标

关键词：**安静、克制、清晰、轻、完整。**

不是传统 SaaS Dashboard，不追求“组件很多所以显得功能丰富”。用户注意力应该停留在学习内容、当前行动或正在查找的资料上，而不是 UI 本身。

目标状态：

> **紧凑但不拥挤；有留白但每一块留白都有层级作用；边界清楚但不扎眼；每个页面只有一个主要视觉中心。**

## 2. 视觉母版

现有《逸学视觉初版》第一页作为颜色与整体气质参考：

| Token | 值 | 用途 |
|---|---|---|
| 主强调 | `#D1E043` | 当前态、关键动作、极少量重点 |
| 强调深 | `#CBDC28` | 主强调的较深状态 |
| 柔和绿 | `#E5F3E7` | 低权重状态背景、日程块等 |
| 辅助黄绿 | `#DAE668` | 次级强调，谨慎使用 |
| 细分隔 | `#EEEFE9` | 分隔线、弱边界 |
| 暖白 | `#FBFCF7` | 页面主背景 |

强调色是**稀缺资源**。不得把大面积页面背景、多个大 Card 或所有按钮都染成绿色。

## 3. 字体

- 正文、交互、列表、按钮：优先 `Noto Sans SC` 或等价清晰中文无衬线体；
- 品牌字样 `Yixue / 逸学` 可以保留原视觉中的衬线气质；
- 不把品牌字体扩散到普通页面标题、列表和操作；
- 字重承担主要层级，不依赖颜色堆叠。

## 4. 信息层级

主要依靠：

1. 位置；
2. 对齐；
3. 字号；
4. 字重；
5. 间距；
6. 明暗；
7. 最后才是强调色。

不要首先使用：重边框、重阴影、大色块、大面积圆角卡片。

## 5. 留白与密度

原视觉的“高留白”不是“越空越高级”。留白只承担三种作用：

- 分隔不同信息组；
- 让主任务获得注意力；
- 为阅读与操作提供呼吸空间。

若一块空白不能解释它在分组、聚焦或可读性上的作用，应优先收紧。

相关内容之间距离要小于不同组之间距离；页面不应因为过大的纵向间距变得松散。

## 6. 卡片

**卡片不是默认容器。**

只有以下情况考虑卡片：

- 对象确实独立；
- 有明显可点击边界；
- 背景层级需要与周围内容区分。

普通分组、列表、摘要优先使用“文字 + 间距 + 淡分隔线”。

禁止：

- 卡片套卡片；
- 每个 section 都包 Card；
- 20px+ 大圆角作为全局默认；
- 通过阴影制造层级。

## 7. 导航与状态

- 全局导航使用胶囊心智；当前页面有明确但不过度的强调；
- 学科内局部 Tab 当前项采用强调文字 + 短下划线；
- 候选状态要可识别，但不比已确认内容更抢眼；
- 辅助入口如“历史对话”“现状”保持轻量。

## 8. 边框与阴影

- 边框：低对比、细；优先 `#EEEFE9` 一类；
- 阴影：默认无或极弱；
- 需要区分层级时，先用留白、底色或分隔线，再考虑阴影。

## 9. 文案

界面文案简短、功能性强，不解释系统自己能做什么。

避免：

- “智能为你推荐……”；
- “根据你的学习画像……”；
- 大段引导性副标题；
- 重复页面名称；
- Agent 自行生成的营销式文案。

## 10. 响应式

MVP 桌面优先、单版本响应式适配手机。

移动端可以改变排布，但：

- 核心任务不能被阻断；
- 信息语义与操作结果保持一致；
- 桌面的辅助抽屉可在手机转为覆盖层，但不能因此变成长期常驻页面；
- 不为了手机端另造一套产品结构。
