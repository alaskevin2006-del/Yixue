# 逸学 Yixue

按学科组织学习对话、显式引用资料、主动回顾和学习记忆。产品行为以 `docs/` 为准。

## 本地运行

需要 Node.js 24。安装锁定依赖，将 `.env.example` 复制为 `.env`，设置独立的应用管理员密码，以及兼容 Chat Completions 的模型地址、密钥、模型名称。

```sh
npm ci
npm run dev:local
```

打开 http://127.0.0.1:3000 ，使用配置的管理员账号登录。管理员可创建普通账号；没有公共注册入口。首次密码只用于初始化，重启不会覆盖已修改的密码。SQLite 和上传文件默认保存在 `.data/`；环境文件、数据目录不提交到 Git。

未配置模型时，非 AI 数据操作仍可使用，AI 请求明确报告未配置。生产入口不使用演示回答。

## 已接入的流程

- 账号登录、退出、修改密码，管理员创建账号、重置密码及停用。
- 学科空间、图标、学习对话、真实消息保存、模型回答与失败重试。
- 私人资料、公共资料、课程、投稿审核；接受投稿产生独立公共资料。
- 文本与文档提取、指定页段、明确选择对话参考；不可读或仅部分提取时显示实际状态。
- 主动选择来源回顾、提取候选、编辑保留或忽略、学习记忆 Active/Inactive、版本冲突保护与来源可用性。
- 学科现状手动保存或预览后采用；首页行动建议及本次安排。

普通学习不会自动改写记忆或现状。新对话不会继承资料引用。删除原始对话后，独立保留的学习记忆仍存在，来源显示不可用。首页安排仅属于当前页面会话。

## 检查与部署

```sh
npm run test:backend
npm run test:e2e
npm test
```

浏览器测试默认使用本机 Edge，可通过 `YIXUE_BROWSER_CHANNEL` 选择已安装的 Chrome。测试使用真实数据库和 HTTP 服务，但外部模型使用明确标记的测试适配器；测试通过不等于真实模型或远程服务器验收。

部署、HTTPS、更新回滚和数据库与文件成对备份恢复见 [deploy/README.md](deploy/README.md)。接口约定见 [engineering/API.md](engineering/API.md)，当前真实验证结果及外部阻塞见 [engineering/progress.md](engineering/progress.md)。

## 历史静态演示

`npm run demo:product` 在 http://127.0.0.1:3001 启动独立本地演示，保留旧交互用于对照。该入口的数据与回答为演示内容，不能作为生产入口或功能验收依据。
