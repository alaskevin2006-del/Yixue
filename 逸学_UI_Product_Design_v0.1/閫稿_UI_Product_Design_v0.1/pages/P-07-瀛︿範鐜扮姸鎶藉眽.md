# P-07｜学习现状抽屉

## 作用

在不离开当前任务的情况下查看或纠正 `Subject State`。

## 一级状态：总览

右侧抽屉：

```text
学习现状                                            ×

C++
极简摘要                                             ›

高等数学
极简摘要                                             ›

概率论
极简摘要                                             ›
```

摘要只用于快速浏览，不复制完整 Subject State。

## 二级状态：单学科完整现状

```text
‹ 学习现状                                          ×

C++
完整的最小充分 Subject State

编辑现状
```

仍留在同一个抽屉内，不跳转新页面。

## 编辑状态

当有用户近期明确提供的新现状可作为依据时：

```text
C++ · 现状更新                                      ×

当前记录
...

最近你提到
“...”

建议更新
...

编辑                         采用
```

建议只是候选；采用前不得覆盖当前状态。

## 禁止项

- 自动根据日程完成情况写回；
- AI 独立推断后直接更新；
- 多版本时间线；
- 进度百分比；
- 把现状常驻在主页面。
