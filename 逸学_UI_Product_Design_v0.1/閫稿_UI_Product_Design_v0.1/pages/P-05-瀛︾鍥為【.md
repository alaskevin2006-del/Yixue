# P-05｜学科空间 · 回顾

## 页面主任务

查看近期学习与值得继续关注的信息，并在用户需要时主动发起复盘。

## 回顾首页

```text
C++    学习   回顾   资料                                      现状

最近学习                                      开始一次复盘
最近有 N 个对话
Conversation 1
Conversation 2
Conversation 3

值得继续关注                                  查看全部
Learning Memory Item 摘要
```

不要给“最近学习”“值得继续关注”各套一个大型外层卡片。

## 开始一次复盘

进入独立的回顾页面状态：

```text
← 回顾

本次复盘
最近学得怎么样？
[用户输入]

参考最近对话
＋ 添加

开始
```

开始后进入复盘对话，完成后进入候选确认页。

## 候选确认

```text
这次有 N 条内容可能值得留下

标题
最小充分内容                         编辑 / 忽略 / 保留
```

每条独立处理，不提供“一键全部保存”作为默认主动作。

## 查看全部

按：

```text
当前值得关注
已形成认识
```

两组轻量纵向列表展示。不要做卡片墙，不显示掌握度评分。
