# UC-01｜首页行动辅助

## 场景起点

用户已有学习目标或已有安排，但因为当天时间、任务、进度或想法发生变化，不确定现在如何推进。

## 用户目标

快速得到一个可执行的近期安排，同时保留最终决定权。

## 系统读取

- 当前可见日程；
- 各学科最小充分 `Subject State`；
- 用户本轮主动提供的时间、目标、变化与约束。

不默认读取完整学习对话、全部 Learning Memory Item 或全部资料。

## 系统行为

1. 用户在首页底部输入自然语言；
2. 信息不足以形成合理建议时，AI 只追问真正影响当前判断的少量问题；
3. 可以直接给建议时，不为了“完整流程”额外追问；
4. 需要形成具体时间安排时，把安排先作为**候选日程**投影到当前日历；
5. 用户可以继续调整；
6. 用户选择“采用”后，候选成为当前安排。

## 用户交互

- 输入框始终属于首页主任务；
- 对话从输入区向上展开，不进入独立聊天页；
- 日历仍作为主要上下文可见；
- 候选出现后提供“继续调整 / 采用”两个直接动作。

## 信息变化

- AI 建议与候选日程不修改 `Subject State`；
- 用户采用日程只改变具体安排；
- 当前 Model 不维护行动历史、完成率、失败记录或自动结转。

## 禁止行为

- 一句话后直接永久写入日程且不给用户确认；
- 自动把“做了什么”推断成新的 Subject State；
- 自动跨天排满长期计划；
- 把首页做成 Todo Dashboard；
- 在首页常驻展示所有学科详细状态。
