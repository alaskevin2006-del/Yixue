# UC-06｜资料投稿

## 场景起点

用户希望把一份资料提交给公共资料库审核。

## 用户目标

完成投稿，并明确知道当前审核状态。

## 系统行为

1. 用户进入“资料库 → 我要投稿”；
2. 上传区域支持选择文件/文件夹；
3. 上传后进入“我的投稿”；
4. 投稿与 Public Resource 分开存在；
5. 审核通过后产生独立 Public Resource，原 Submission Resource 不原地转换；
6. UI 只呈现对用户有意义的状态，例如“审核中 / 已收录”。

## 禁止行为

- 上传后直接显示“已公开”；
- 把投稿和私人资料混为同一对象；
- 用“已发表”替代当前确定的“已收录”语义；
- 在未定义审核行为时自行增加复杂审核流程。
