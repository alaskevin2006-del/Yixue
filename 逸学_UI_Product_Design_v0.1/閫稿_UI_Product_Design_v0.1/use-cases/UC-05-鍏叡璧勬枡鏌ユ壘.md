# UC-05｜公共资料查找

## 场景起点

用户需要某门实际课程的课程学习、作业、考试或备考资料。

## 用户目标

以尽量低的搜索和判断成本找到相关资料。

## 系统行为

1. 用户进入“资料库 → 公共资料”；
2. 可直接搜索课程或资料；
3. 页面同时提供实际课程入口；
4. 进入某课程后显示该课程公共资料列表；
5. 可以使用资料类型、年份、排序等辅助筛选；
6. 资料类型、年份、教师等仅作辅助元信息，不建立新的固定核心层级。

## 页面层级

```text
公共资料
  └─ Course
       └─ Public Resource
```

## 禁止行为

- 在资料库展示学习现状；
- “最近活跃”课程；
- 根据 Subject State 自动推荐资料；
- 把类型、年份做成复杂多级目录；
- 添加无法由现有数据支持的“推荐”“评分”“适合你”等判断。
