# 逸学 Problem

本文记录逸学要解决的学习问题。

## 0. 当前观察范围

**中山大学软件工程学院学生**

---

## 1. 学习资料获取与判断成本高

### 问题定义

**学生难以以较低成本找到与当前学习任务真正相关、版本合适且值得使用的学习资料。**

### 可观察摩擦

资料长期分散在群聊、网盘、学长学姐个人存档和其他渠道中。在需要寻找课程学习、作业、考试或备考资料时，学生不仅需要反复搜索、询问和下载，还需要判断资料是否与当前课程相关、版本是否合适、质量是否可信、哪些资料真正值得优先使用。

例如备考高数时，搜索结果中可能同时出现往年试卷、课程资料、学长学姐整理和机构通用资料。它们都可能有参考价值，但与当前课程和考试的相关性、重要性并不相同。

### 现有替代为何仍不足

群聊、网盘和搜索工具能够保存或传播文件，但通常不能降低跨渠道寻找成本，也缺少稳定的课程语境来帮助学生判断资料的相关性、版本和实际价值。资料即使曾经被某届学生找到，下一届仍可能重新经历相同的搜索和筛选过程。

## 2. 过去的学习难以有效延续到当前学习

### 问题定义

**学习者过去真实发生的学习经历，很难以低成本、可靠地成为当前学习的有效上下文与依据。**

### 可观察摩擦

学生在做作业、自学教材、看 PPT、刷题、复习和讨论等学习过程中，会经历错误、卡点、理解变化、纠正、遗忘和重新掌握。

但这些历史经历并不会自动具有稳定的当前意义。一个月前做错的问题，今天可能已经掌握；过去曾经理解的内容，今天可能已经遗忘；当时有效的认识，也可能随着后续学习而被修正。

因此，当学生再次遇到相关知识点、准备考试或进行查缺补漏时，真正困难的不只是“过去记录在哪里”，还包括：

- 当前问题与过去哪些学习经历有关；
- 过去的错误后来是否真正纠正；
- 当时形成的理解现在是否仍然成立；
- 过去“会做”是否意味着现在仍然掌握；
- 哪些历史经历值得在当前重新调取或验证。

结果是，过去已经发生的学习很难自然改变当前的判断和学习行为，相同的错误、困惑和探索过程仍可能重复出现。

### 现有替代为何仍不足

聊天记录、作业记录和笔记可以保存过去发生过什么，但历史记录本身不能直接回答“现在怎么样”。

原始记录通常分散且缺少当前语境；人工笔记可以保留结论，却容易把过去某一时刻的认识固化下来。即使历史信息被完整保存，学习者仍需要重新判断哪些内容与当前问题相关、哪些已经失效、哪些需要重新验证。

因此，现有工具更擅长保存历史，却难以低成本地让历史学习持续为当前学习提供有效依据。

## 3. 学习目标难以转化为持续行动

### 问题定义

**学生在已有学习目标的情况下，面对多个任务、当前学习状态和持续变化的现实约束，仍难以持续形成清晰、可执行且能够随现实调整的下一步行动判断。**

### 可观察摩擦

学生往往知道自己需要完成什么，但当多个课程目标、作业、考试、有限时间和不断变化的学习进展同时存在时，很难把这些因素持续整理成明确的下一步行动。

例如临近期末时，每门课程需要完成什么可能都很清楚，但多门考试、作业和其他现实约束叠加后，学生容易陷入“不知道先做什么、现在能做什么、原来的安排是否还适用”的状态。即使已经形成安排，随着学习进度、时间和外部任务变化，也需要重新判断和调整。

### 现有替代为何仍不足

Todo、Calendar 等工具能够记录任务和时间，通用 AI 也能够生成一次性的学习计划，但前者主要保存已有安排，后者通常依据某一时刻的信息形成建议。现实情况变化后，学生仍需要重新梳理目标、进展和约束，才能形成新的行动判断。
