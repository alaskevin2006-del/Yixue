# 逸学｜Visual Acceptance

每次只验收一个页面。页面未通过，不进入下一个页面。

## 1. 页面级必过项

### A. 主视觉中心

- [ ] 进入页面 2 秒内能判断当前主要任务；
- [ ] 只有一个明显主内容区域；
- [ ] 辅助内容没有与主任务同等视觉重量。

### B. 信息密度

- [ ] 没有明显无功能的大面积空白；
- [ ] 同组内容距离明显小于跨组距离；
- [ ] 不因为“高级感”故意拉大页面高度。

### C. 卡片与边界

- [ ] 没有把普通 section 全部做成 Card；
- [ ] 没有卡片套卡片；
- [ ] 边界主要靠排版、间距和淡分隔线；
- [ ] 没有重阴影。

### D. 颜色

- [ ] 页面大部分为暖白/中性色；
- [ ] 强调色只服务当前态、关键动作或必要状态；
- [ ] 不存在大片灰绿色/黄绿色背景抢夺注意力。

### E. 字体与层级

- [ ] 正文和交互使用统一无衬线体系；
- [ ] 品牌字体没有扩散到普通标题；
- [ ] 标题、副标题、正文、弱信息层级可一眼区分；
- [ ] 没有通过大量不同字号制造层级混乱。

### F. 产品语义

- [ ] 没有新增 Page Spec 中不存在的模块；
- [ ] 没有新增统计、Badge、推荐、进度、掌握度；
- [ ] 没有重复标题或解释性文案；
- [ ] 辅助信息按需出现，没有重新变成常驻侧栏。

## 2. 页面专项检查

### 首页

- [ ] 日历是主视觉中心；
- [ ] 输入框固定在自然可达位置；
- [ ] 对话向上展开而非另开主区域；
- [ ] 候选日程直接出现在日历；
- [ ] “现状”只打开抽屉。

### 资料库

- [ ] 首页只有“公共资料 / 我要投稿”一级局部导航；
- [ ] 没有“资料库 / 公共资料 / 课程公共资料 / 全部课程”的标题堆叠；
- [ ] 点击课程进入独立课程视图；
- [ ] 没有现状、最近活跃等学习信息。

### 学科学习

- [ ] 默认进入“学习”；
- [ ] 历史对话不是常驻侧栏；
- [ ] 聊天区是唯一主内容；
- [ ] “现状”不挤入主内容。

### 学科回顾

- [ ] 最近学习和值得继续关注以轻量分组呈现；
- [ ] 复盘有“输入/参考 → 对话 → 候选确认”完整状态；
- [ ] Memory Item 不是卡片墙。

### 学科资料

- [ ] 私人资料位于 Subject Space；
- [ ] 只有搜索、上传、列表等必要结构；
- [ ] 没有“历史资料”等自行分类。

## 3. 响应式检查

至少检查：

- 桌面宽屏；
- 普通笔记本宽度；
- 约 390px 手机宽度。

移动端允许布局重排，但不能丢失核心操作或改变产品语义。

## 4. 截图验收方式

每一轮修改必须保留：

```text
设计参考 / 修改前 / 修改后
```

三者并排检查。

视觉相似不是唯一标准；若“像设计稿但产品语义错”，仍视为未通过。
