# P-03｜学科空间总览

## 页面主任务

让用户快速进入一个学科空间。

## 默认结构

```text
学科空间                   搜索学科…      ＋

C++   高等数学   概率论   数据结构 ...
```

## 视觉层级

- 学科本身就是主要对象；
- 不需要“最近活跃”这一额外分组；
- 不需要学习统计、进度、最近对话摘要等预览；
- 学科入口应紧凑、平静，不做超高大卡片。

## 未定义行为

“＋”新增学科的完整业务规则尚未在现有 Product/Model 中冻结。Agent 不得为了补全页面自行设计复杂建课流程；若实现必须维持最小占位并单独确认需求。
