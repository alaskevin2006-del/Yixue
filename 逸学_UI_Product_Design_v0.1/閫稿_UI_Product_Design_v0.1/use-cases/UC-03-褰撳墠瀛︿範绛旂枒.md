# UC-03｜当前学习答疑

## 场景起点

用户正在课堂、教材、PPT、题目、IDE 等外部环境中学习，在某个学科遇到具体疑问、错误或卡点。

## 用户目标

尽快得到直接、贴合当前理解程度的帮助，而不是重新开始一套课程学习流程。

## 系统行为

1. 用户进入对应 Subject Space，默认落在“学习”；
2. 可以继续当前 Conversation，也可以“新对话”；
3. AI 依据当前 Conversation 与必要外部信息构造最小充分 Current Context；
4. 回答遵循长期稳定的回答规则：直接回答真实问题，避免信息墙、答非所问和解释粒度失配；
5. 用户继续追问或纠偏时，当前上下文随问题变化；
6. 用户需要查看过去对话时，打开“历史对话”抽屉，选择后自动关闭抽屉并进入该对话。

## 信息变化

- Conversation 保存原始交互；
- Current Context 只服务当前回答，不作为长期学习状态；
- 一次对话默认不会自动生成 Learning Memory Item；
- 离开学习页不要求额外“结束学习”流程。

## 资料使用

如果用户明确调用某份资料，资料内容可以进入当前回答；资料未被用户调用时，不因为“与该学科有关”就自动加入。

当前视觉稿未明确资料调用入口的具体交互，因此 Agent 不得自行新增复杂附件/RAG 操作流程。

## 禁止行为

- 常驻历史对话侧栏；
- 常驻学习记忆面板；
- 每次回答后强制“是否沉淀”；
- 自动显示大量过去学习信息；
- 为了证明系统智能而增加解释型 UI。
