# 学习行动辅助 Model

## 1. 模型范围

学习行动辅助 Model 只描述为了持续辅助用户判断下一步行动而需要长期维护的信息。

用户当次输入、现实约束、AI 建议和某日排程均属于具体行动判断过程中的临时信息，不作为稳定 Model 对象。

## 2. 核心对象

### Subject State

每个学科空间维护一份 `Subject State`。

`Subject State` 是：

> **对该学科当前仍会影响后续行动判断的信息，按照最小充分原则整理形成的自然语言现状。**

其中可能包含：

- 当前目标或背景；
- 当前学习情况；
- 当前存在的问题；
- 当前准备如何继续推进；
- 其他会实质影响后续行动判断的信息。

以上仅为可能内容，不构成固定分类或字段。

`Subject State` 可以不完整，也可能因用户在系统外学习而过时。系统不追求持续准确追踪用户真实学习状态。

## 3. 使用关系

一次行动判断可以参考：

```text
各学科 Subject State
        +
用户当前提供的信息
        ↓
AI 提供行动建议
        ↓
用户决定如何安排
```

`Subject State` 只是行动建议的参考依据，不决定用户行动。

AI 建议、用户形成的某日安排以及已经过去的安排均不写回 `Subject State`；只有用户主动提供新的学科现状信息时，才产生状态更新。

## 4. 必要不变量

1. 每个学科空间只维护一份当前 `Subject State`。
2. `Subject State` 使用自然语言表达，不预设固定字段或完整结构。
3. `Subject State` 遵循最小充分原则，只保留仍会实质影响后续行动判断的信息。
4. `Subject State` 只在用户主动提供新的现状信息时更新，不自动根据系统内外行为推断现实变化。
5. AI 可以整理更新内容，但系统推测不得未经用户确认写入 `Subject State`。
6. 学科现状、AI 行动建议和具体日期的安排相互独立；任何一方都不自动修改另一方。
7. AI 只辅助用户判断下一步行动，最终决定始终由用户作出。
8. MVP 不维护行动历史、完成率、失败记录、自动结转、独立待处理事项或额外全局状态。
